## 📂 Proyectos Destacados

### 🏥 [Clínica Post Pandemia](https://github.com/LujoMontero/clinicapostpandemia)
Sistema web MVC para gestión de pacientes, médicos y citas médicas.
- Spring Boot 3.4 · Java 21 · JPA/Hibernate · MySQL · Thymeleaf
- Relaciones `@OneToMany` / `@ManyToOne`, validaciones servidor, Lombok

### 🚌 [Control de Reclamos – Transporte](https://github.com/LujoMontero/controlreclamos_transporte)
Sistema para registro y seguimiento de reclamos en empresa de transporte.
- Arquitectura en capas: Controller → Service → Repository
- Spring Boot · Java · MySQL · Spring Data JPA

### 🤖 Landing Page Médica con Chatbot IA
Landing page para clínica con chatbot inteligente para agendamiento de citas.
- React · Vite · Tailwind CSS · Firebase · Claude API (LLM)
- El bot interpreta intenciones del usuario y registra citas en Firestore

### 📦 [API REST – Gestión de Inventario](https://github.com/LujoMontero)
API REST con autenticación JWT, documentación Swagger y pipeline CI/CD.
- Spring Boot · MySQL · Docker Compose · JUnit · Mockito · GitHub Actions
